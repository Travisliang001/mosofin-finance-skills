## Output Quality Standards

All of the original standards, plus the Mosofin ones.

- Acquirer and acquisition date determined **per control**
- Business-vs-asset screen applied
- Consideration measured at fair value at the acquisition date, by component; **transaction costs
  expensed**
- Identifiable assets and liabilities (including separable intangibles) recognized at fair value
- Goodwill (or bargain purchase) computed correctly; **NCI measured per framework choice**
- Step-acquisition remeasurement applied where relevant
- Contingent consideration classified and a remeasurement plan set
- Measurement-period mechanics in place for the year following
- Subsequent accounting handed to the amortization / impairment skills
- Disclosure data complete (including pro forma where required)
- **Valuation specialist involvement flagged for fair values**
- File naming consistent

**Mosofin additions:**

- The workspace was confirmed **by name** and the user said yes before any data was read
- **Acquirer and acquiree are each named by `display_name` with their role stated**, and every
  figure identifies which entity it came from
- Every in-scope company file is named by `display_name`; every excluded one is named **as
  excluded**, with the consequence stated
- The capability map was discovered **this run** via Gate 2, **separately for each entity** — never
  recalled from a previous conversation or from this file
- **No book value is presented as a fair value**; every line where they coincide says whether that
  was a conclusion or a default
- **Transaction-cost treatment was tested against the acquirer's ledger** and the result reported
- Every fair value names its **valuer and report date**, or is listed as outstanding with an owner
- The acquiree's post-acquisition results and prior-period comparatives state whether they were read
  from its ledger or supplied
- **A pro forma states which adjustments were applied**, and is never two P&Ls simply added together
- The measurement-period end date is stated, and the one-year boundary tracked
- Every task carries its verdict (`[auto]` / `[gated]` / `[manual]`), the tool used, and that tool's
  policy, in the coverage sheet
- `mock` status is reported wherever it applies, and **no acquisition entry, goodwill figure or
  disclosure rests on mock data**
- Every figure traces to a tool result in this conversation or to labelled user-supplied evidence;
  the answer ends with a single **Data sources** line
- Every jargon term carries a plain-language gloss at first mention, with the professional term kept
  alongside
- No internal numeric ids and no raw `data_source_id` values appear in anything the user sees
- **No consideration amounts, fair values, goodwill figures or valuation report contents are
  persisted** into a skill bundle; every persisted preference states the datasource, `display_name`
  and role it covers
- Nothing was written back to any system — the acquisition entry is a proposal for a human to post
