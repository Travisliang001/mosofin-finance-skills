## Output Quality Standards

All of the original standards, plus the Mosofin ones.

- **Each digital asset classified per current framework guidance** (US GAAP ASU 2023-08 scope, IFRS IAS 38
  / IAS 2, etc.) — **not based on outdated rules**
- **Measurement model applied correctly and consistently**
- **Transactions recognized at fair value where required; cost basis tracked at lot level**
- **Mining / staking revenue at fair value at receipt**
- **Custody and counterparty risk assessed and disclosed**
- **Impairment (where cost model) applied per framework, with reversals only where permitted**
- Disclosures current with evolving requirements
- **Tax treatment flagged for a specialist (not addressed in this skill)**
- Internal controls noted; complex DeFi, forks and airdrops flagged for a specialist
- File naming consistent
- **No reliance on superseded guidance; explicit current-source confirmation in open items**

**Mosofin additions:**

- The workspace was confirmed **by name** and the user said yes before any data was read
- Every in-scope company file is named by `display_name`; every excluded one is named **as excluded**
- The capability map was discovered **this run** via Gate 2 — never recalled from a previous conversation
  or from this file
- **No recorded carrying value is presented as evidence that an asset exists**; existence is evidenced by
  the wallet or custodian statement, with its as-at date stated
- **Every fair value carries its principal market and its timestamp**; none is supplied from memory
- **The completeness sweep was run and its result stated**, including when nil and including when it could
  not be performed
- **The fiat leg and the crypto leg of every transaction are distinguished**, and cash to an exchange is
  never presented as a purchase
- **The date the applicable standard was last confirmed is recorded**, and no standard's current content is
  asserted from memory
- Where the US GAAP legacy impairment model applies, the output states whether a **price series** was
  available or only a closing price
- Every task carries its verdict (`[auto]` / `[gated]` / `[manual]`), the tool or external source used, and
  its as-at date, in the coverage sheet
- `mock` status is reported wherever it applies, and no carrying value or disclosure rests on mock data
- Every figure traces to a tool result in this conversation or to labelled user-supplied evidence; the
  answer ends with a single **Data sources** line
- Every jargon term carries a plain-language gloss at first mention, with the professional term kept
  alongside
- No internal numeric ids and no raw `data_source_id` values appear in anything the user sees
- **No wallet addresses, private keys, seed phrases, exchange credentials, holdings or prices are
  persisted** into a skill bundle; every persisted preference states the datasource and `display_name` it
  covers
- Nothing was written back to any system — every entry is a proposal for a human to post
