# XBRL tagging: the map, the extensions, the checks

> Tag map, extension rules and calculation checks.

**Skill:** `xbrl-tagging-checklist`  ·  **Area:** Public reporting  ·  **Automated with Mosofin connected:** 39%  ·  **Read-only**

## What it does

Gives a disciplined approach to XBRL and inline XBRL tagging for SEC filings: the tag map, governance over custom extensions, dimensional tagging, calculation and consistency checks, the calculation relationships the statements imply, and the validation and independent review workflow. States plainly that it cannot read the filing draft or the tagged file, which you supply. Reads the financial statement structure through a connected Mosofin workspace when you agree, or works from an uploaded draft and tag map.

## When to use it

Use it when you ask about XBRL or iXBRL tagging, a tag map, custom extensions, calculation errors, or XBRL validation and review.

Not for:

- Preparing the filing as a whole (use [sec-10q-10k-prep](sec-10q-10k-prep.md)) or the notes (use [notes-to-financial-statements](notes-to-financial-statements.md)).

## What it asks you first

Before it reads anything, it asks, in one message:

| It asks | Why |
|---|---|
| *Use Mosofin as the data source for this run, or upload the data yourself?* | Decides the path. Mosofin is the connection to your books and other linked platforms; with it the skill reads from there, without it you upload and the checks are the same |
| *Which company, filing and period?* | Sets the scope |
| *Which taxonomy version is in use?* | It changes every year |
| *Can you supply the filing draft and the prior filing's tag map?* | Neither can be read through Mosofin |
| *Do you have the validation tool's output?* | The starting point for the error review |
| *Who performs the independent review?* | A second person must check the tags |

## With or without Mosofin

With a Mosofin workspace connected, and only after you agree, the skill reads the figures from your own books. Without a connection it runs the same analysis on files you upload, and the output says which figures came from where.

If you upload the data yourself:

| Upload | Needed? | Format |
|---|---|---|
| **Filing draft** | Required | PDF or DOCX |
| **Prior tag map** | Required for consistency | XLSX |
| **Validation output** | Recommended | PDF or text |
| Taxonomy version and reviewer | Required | Type it in the chat |

Every uploaded file is checked before any work starts: that it is the right kind of document, for the right company and period, and usable.

## What you get

Produces the tag map review and checklist, and tags or files nothing.

Every run ends with a coverage sheet: what was checked, what was estimated, and what could not be done and why.

## What it never does

- **Asks before using Mosofin.** A connected account is not permission to read it.
- **Never writes, updates or deletes anything, in any system.**
- **Never assigns an element from memory.** Element names come from the taxonomy version you state.
- **Never approves a custom extension.** It records the case for one and leaves the decision to the reviewer.
- **Never treats a valid file as a correct one.** A wrong element can pass validation.
- **Never tags or files anything.**
