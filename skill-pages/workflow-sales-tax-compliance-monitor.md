# Sales tax nexus monitor (workflow)

> Checks Mosofin data on a schedule or on demand and proposes registration reviews.

**Workflow:** `sales-tax-compliance-monitor`  ·  **Runs in:** n8n  ·  **Read-only**

## What it does

Totals sales and transaction counts by ship-to state over a trailing window and compares them with each state's economic-nexus thresholds. Flags states crossed where the company is not registered, and states approaching the line.

- Sales by ship-to state over `window_start`..`as_at` from Mosofin invoices (file fallback).
- Each state is tested on sales and, where the state has one, transaction count; the higher percentage counts.
- Crossed and not in `registered_states` → registration review; at or above `warn_pct` → approaching.
- Thresholds are settings, not law: the README and every action say to confirm them.

## When it runs

Runs monthly on its own, and whenever something sends it a request.

With a Mosofin data source set, it reads customer invoices through the Mosofin gateway. Where a file you send covers the same data, the Mosofin figures are used first and the file is the fallback.

## What you send it

| File | What it must be | Required |
|---|---|---|
| `sales` | sales by invoice with ship-to state | no |

Every file is checked on its content before any work: right kind of document, right company, usable. A rejected required file stops the run; a rejected optional file is skipped and named in the result.

## What you can change

Every setting sits in one place, and any of them can be overridden for a single run.

| Setting | Meaning |
|---|---|
| `company` | Company the run is for; a file naming another company is rejected |
| `currency` | Reporting currency, echoed in the envelope |
| `datasource` | Mosofin datasource name (e.g. quickbooks, xero) |
| `window_start` | Start of the measurement window (e.g. 12 months back) |
| `as_at` | As-at date (YYYY-MM-DD); empty = run date |
| `warn_pct` | Flag a state once sales or transactions reach this percent of its threshold |
| `registered_states` | States where the company already collects and files |
| `thresholds` | Per-state { amount, transactions } (null = no count test); `default` for states not listed. Confirm against current state rules before relying on them. |

## What comes back

One result for the next step to use: an email connector, a chat post, a dashboard or another tool. It holds the findings, the totals, what could not be done and why, and the proposed actions, each waiting for a person's approval.

**It proposes:** Registration reviews.

## What it never does

- **Never posts, sends, pays or changes anything.** The only outbound calls are reads through the Mosofin gateway.
- **Never acts on its own proposals.** An email draft, a journal entry, a hold or a payment is handed to a person to approve first.
- **Never trusts a file by its name.** Each file is checked on its content before it is used.
